# Archivrichtlinie

## Zweck
Der Archivbereich haelt historische Arbeits- und Zwischenartefakte fuer Nachvollziehbarkeit vor,
ohne dass sie als aktuelle normative Quelle interpretiert werden.

## Grundregel
- Ein Thema hat genau eine aktive Source of Truth.
- Historische Dokumente bleiben erhalten, werden aber klar als historisch markiert.
- Aktive Dokumente verweisen auf Historie, statt Inhalte zu duplizieren.

## Was als historisch gilt
- Schritt- und Signoff-Dokumente aus frueheren Umsetzungsphasen.
- Momentaufnahmen mit zeitlich begrenzter Aussagekraft.
- Incident-/Sonderberichte, die nicht das laufende Runbook ersetzen.

## Pflege
- Neue PRs duerfen historische Inhalte ergaenzen, aber nicht als normative Primarquelle verwenden.
- Bei Konflikten zwischen Historie und aktiver Doku gilt immer die aktive Source of Truth.
